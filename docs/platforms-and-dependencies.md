# Platforms, dependencies and licensing

## Platform status

| Target | Current scope |
| --- | --- |
| Windows x64 | Windows 10 or newer; MSVC 2022 source builds, dynamic CRT, UTF-8 source/paths; Release CRT included in packages |
| Linux x86_64 | X11/GLX, including Xwayland; GCC/Premake builds. Official Ubuntu 24.04 packages require glibc 2.39+. Native Wayland is not implemented |
| Graphics | OpenGL **4.1 core** minimum; capability checks select supported resource/shader paths. Later GL features are optional, rather than a higher minimum |
| macOS | Experimental native arm64/macOS 27.0+ Xcode foundation; real Apple OpenGL 4.1 regression evidence, application qualification and packaging pending. [Commands and status](design/macos-port.md) |
| Other graphics backends | Not implemented; 3D/PBR/IBL follow the macOS milestone |

Linux HD4000 accelerated GL4.2 and forced GL4.1 through Xwayland, software rendering and Windows CI are distinct evidence. A forced Mesa version is not an Apple-driver/macOS test. Windows software CI does not establish physical GPU, controller or monitor/DPI acceptance. The owner reports hands-on acceptance complete and approves integration; this approval does not add independently enumerated hardware or reader-review results to the automated evidence.

The current UI endpoint includes authored layout/text/styles, controls/scrolling/screens/focus/remappable input, native authoring and bounded history. Limits include finite authored lists, declared font coverage and committed-text input without native IME preedit/candidate positioning. [Runtime UI](runtime-game-ui.md) gives the exact supported behavior; it does not promise universal language coverage, rich-text editing, virtualization or accessibility APIs.

## Source prerequisites versus pinned inputs

[Getting started](getting-started.md#prerequisites-installed-by-you) gives install commands for Windows, Ubuntu and Arch/CachyOS. Users install the host compiler/development packages, Git, Python/pip, Linux Mono development profile or Windows .NET Framework 4.7.2 targeting pack. Bear/GDB and screenshot tools are optional; no capture dependency is required to build or play.

The checkout owns its dependency identities. Clone recursively, keep gitlinks pinned and use the canonical setup/build commands. Do not update submodules with `--remote`, edit vendor source or install system GLM to hide missing includes.

| Input | Authority / acquisition |
| --- | --- |
| GLFW, GLM, ImGui, ImGuizmo, spdlog, YAML, Box2D, font generators and typography libraries | [Git submodules](../.gitmodules), including nested msdfgen/FreeType/dlg; exact gitlinks in the checkout |
| Premake and PyYAML | [toolchain.json](../scripts/internal/toolchain.json); setup prepares project-owned Premake and PyYAML 6.0.3 under `build/tools` |
| shaderc, glslang, SPIR-V Headers/Tools and Cross | [shader-tools.json](../scripts/dependencies/shader-tools.json); source-pinned builds generated by Premake, not a Vulkan SDK requirement |
| Mono | [mono.json](../scripts/dependencies/mono.json); Windows SDK/profile tracked; Linux complete system SDK or checksum-pinned isolated SDK; explicit `HAZEL_MONO_SDK` is honored |
| miniaudio | [PROVENANCE.json](../Hazel/vendor/miniaudio/PROVENANCE.json); 0.11.22 pinned source and licenses |
| HarfBuzz / libunibreak / SheenBidi | [Typography ledger](../scripts/dependencies/licenses/typography/NOTICE.md): 12.3.2 / 8.0 / 3.0.0, Unicode 17 and shipped notices |

Setup acquires missing checkout-owned tools/inputs; it does not install system packages. Prepared games bundle runtime dependencies, without compiler SDKs. The [upstream import record](migration/PROVENANCE.md) describes the historical source foundation; its old counts/checkpoints are not current qualification.
