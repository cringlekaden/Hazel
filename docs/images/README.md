Fresh captures use disposable project/profile/save directories, matching compiled scripts and the existing owned-window `Desktop` helper. Configure panels/camera through a private workspace and normal native controls, capture only that application's client, then close it. No user profile/draft/save is capture scratch space. No capture server or mandatory screenshot dependency is added. Pillow, already available locally, was used only for lossless PNG optimization/cropping; screenshots are not composited or retouched.

Keep UI text readable and filenames/alt text descriptive. Relative image links render on GitHub; detailed editor images also have full-resolution links where useful. Temporary captures stay outside tracked documentation. New images contain no personal desktop content, usernames or source-SDK paths. Original legal notices and scene data remain with their owners.

The older `meadowrun-{title,play,complete}.png`, `skybound-{title,play,over}.png` and design/Authoring images are retained historical evidence. Current public guides use the explicitly selected images above rather than treating old pre-runtime-UI menus as current. No image demonstrates controller/DPI, Windows GPU or competent-reader acceptance.
