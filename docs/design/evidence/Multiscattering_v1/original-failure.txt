## Blocking finding: intrinsic direct energy

The split-sum IBL furnace closes because both SS and compensation use the same
legacy LUT moments. That does **not** establish conservation of the analytic
lighting BRDF. Independent converged VNDF integration of the actual SS lobe,
combined with separately integrated compensation/diffuse, finds:

| Material / r / NoV | Intrinsic direct reflected energy | IBL furnace |
| --- | ---: | ---: |
| Perfect reflector / .045 / .01 | 1.02955095 | 1 |
| White dielectric / .045 / .01 | 1.01437423 | 1 |
| Perfect reflector / 1 / 1 | .99520578 | 1 |

These fail the predeclared ±.003 reflected-energy gate. The r=1 normal-view
analytic SS energy is exactly `1-ln(2)=.3068528194`, whereas the preserved
sampled LUT gives approximately .3116532877. Compensating the LUT's missing
energy leaves the direct lobe short. At low roughness, clipping small negative
per-direction deficits while normalizing by `1-Abar-Bbar` additionally amplifies
errors: the average clipped deficit differs from the raw deficit average.
A small raw LUT overshoot is therefore not automatically a small lobe error.

The implementation and the initial point/IBL checks were insufficient to detect
this. A maintained production-shader direct-furnace integration now guards it.
Do not weaken its tolerance, call IBL closure a full BRDF PASS, retint metals,
or add a brightness correction. The requested preservation of current runtime
A/B response prevents replacing that approximation without owner approval.
A separately versioned, converged table can preserve all historical files and
identities while deliberately changing the current runtime response. That is
the recommended next decision, **not an authorized implementation here**.

## Proposed equations and ownership

Preserve fss=D*Vcorrelated*Fschlick, alpha=max(r,.045)^2 and F0=mix(.04,base,m).
E=A+B; bars denote 2 integral_0^1 value(mu)*mu dmu. Fbar=F0+(1-F0)/21.
C=Fbar^2*Ebar/(1-Fbar*(1-Ebar)).
fms=C*(1-Ei)*(1-Eo)/(pi*(1-Ebar)). R=F0*A+B+C*(1-E).
q=1-max(R.rgb); fd=(1-m)*base*qi*qo/(pi*qbar).
IBL retains P(reflect(-V,N),r)*(F0*A+B), adds irradiance(N)/pi*C*(1-Eo),
and uses irradiance(N)/pi*(1-m)*base*qo for diffuse. Nonuniform lighting uses
an irradiance approximation for the new broad terms, independently of accepted SS error.

Pack GPU RGBA=(A,B,Abar,Bbar) in existing EnvironmentResources. Integrate the
actual normalized-coordinate, clamp-edge, piecewise-linear sampler in FP64 at
realization; preserve disk RG32F and identities. Supply canonical immutable A/B
through the existing fallback resource owner. No material/project format, binding,
render ordering, environment convolution, geometric horizon, AO or TAA change.

References: [Kulla–Conty](https://blog.selfshadow.com/publications/s2017-shading-course/imageworks/s2017_pbs_imageworks_slides_v2.pdf),
[Heitz et al.](https://jo.dreggn.org/2016_microfacets.pdf),
[Fdez-Agüera](https://jcgt.org/published/0008/01/03/paper.pdf),
[DSPBR](https://dassaultsystemes-technology.github.io/EnterprisePBRShadingModel/spec-2022x.md.html).

## Implemented numerical limits

`ForwardPBR.glsl::surfaceEnergy` computes common per-surface values once;
`direct` samples only light-direction A/B in addition. All single-scattering D/V/F
expressions and the reflection-directed split sum are retained verbatim.

The denominator for C is evaluated as `(1-Fbar)+Fbar*Ebar`. Deficits are
`max(1-A-B,0)` and `max(1-Abar-Bbar,0)`; raw A/B remain unchanged for SS.
At exactly zero average deficit the compensation lobe is its analytic zero limit.
No epsilon roughness/view clamp or new threshold is used.

For scalar f=maximum(F0), define t=f+(1-f)/21 and
`k=(20/21)*(1+t*Ebar)/((1-t)+t*Ebar)`. Then
`q=(1-f)*(A+k*missing)` and `qbar=(1-f)*(Abar+k*missingAverage)`.
The direct diffuse coefficient factors out `(1-f)` before division:
`(1-f)*(Ai+k*di)*(Ao+k*do)/(pi*(Abar+k*dbar))`.
It tends continuously to zero at f=1; no division by a vanishing qbar occurs.
Zero diffuse shape average returns zero. The exactly degenerate C denominator
uses its unit-reflector limit. Real canonical tables have positive Ebar.
Small inherited A/B overshoot can still create SS furnace error; new terms do
not erase it. Numerical tolerances report that error rather than retint SS.

`EnvironmentResources::PackBRDFTable` analytically integrates each linear segment
against 2*mu, including constant clamped edge intervals; rows remain linearly
interpolated in roughness. Independent Gauss quadrature checks every row and
bit-compares every packed A/B pair. The canonical direct-only HZLIGHT1 resource
is a byte-identical copy of the existing accepted table. No bake recipe, accepted
identity, disk channel layout, environment filtering or material format changes.

GPU memory: 256 KiB per 128x128 packed table versus 128 KiB previously. The
fallback now also has a full 256 KiB table instead of eight bytes. A view using
one realized environment therefore adds approximately 384 KiB over the historical
implementation, not merely 128 KiB. Native allocation budgets account actual
RGBA32F storage. The transient CPU packing vector is 256 KiB per realization;
there is no table reduction or allocation per draw/frame.
